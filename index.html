The Finger Strategy Game

How to Play

🖐️

Start

Both players start with 1 finger on each hand.

⚔️

Attack

Pick your hand, then tap the opponent's hand to add fingers.

🔄

Split

Move fingers between your hands. Both hands must be alive. Source needs ≥ 2 fingers.

💀

Death

A hand reaching 5+ fingers dies. Lose both hands = Game Over.
